This is the first post on the site. I wanted a home for the projects I am building: a cruise excursion finder for my travel agency and a Python plane tracker.

## The stack

- **Next.js** with the App Router for routing and server rendering
- **TypeScript** so mistakes show up before they reach a browser
- **Tailwind CSS** for fast, consistent styling
- **Vercel** for hosting, with every push to GitHub deploying automatically

The next project is the Viator-powered excursion finder. I will write up what I learn along the way here.
